# IntentCI v1.0.0 Scope

North-star specification: [`v1.md`](../v1.md).

**Success criterion:** All acceptance criteria in [v1.md §38](../v1.md) are met, verified by [acceptance-v1.md](acceptance-v1.md), and published as the breaking `v1.0.0` release.

## Product model

IntentCI v1 is an intent compiler and evidence-based verification control plane:

```text
Requirement (Markdown)
  → Obligation
    → Verifier (provider)
      → Evidence
        → Verdict
          → Repair (bounded)
```

Primary artifacts:

- `.intentci/config.yaml` — project configuration
- `.intentci/requirements/**/*.md` — human-readable requirements with YAML structure
- `.intentci/runs/<run-id>/` — compiled IR, evidence bundles, repair packets (local, gitignored)

## CLI surface

```text
intentci init
intentci compile
intentci verify
intentci explain
intentci repair
intentci status
intentci doctor
intentci schema
intentci version
```

## Exit codes

See [v1.md §17](../v1.md): `0`–`10` (pass, fail, unproven, uncertain, review_required, compile failed, verifier error, internal, usage, repair exhausted, security/boundary).

## Breaking change

v1.0.0 **replaces** the v0.x Product Contract model (`.intentci/contract.yaml`, Change Specs, hooks, `--attest`, exit codes `10/11/12/20/21/30`). See [migration-v0-to-v1.md](migration-v0-to-v1.md).
